DASHBOARD DE CONSULTAS DE EMBARAZADAS

Despliegue en Vercel:
1. Sube esta carpeta a un repositorio de GitHub y conéctalo a Vercel, o usa Vercel CLI.
2. No necesita build command.
3. El archivo index.html es la entrada principal.

NOTA DE PRIVACIDAD:
El dashboard contiene datos agregados de consultas. Antes de publicar, verifica que la información pueda ser expuesta públicamente y que no incluya datos personales o información sanitaria identificable.
